# Red-Balloon-Tracker

سامانه تشخیص و ردیابی بالن‌های هواشناسی قرمز در تصاویر دوربرد با استفاده از بینایی ماشین و یادگیری عمیق.

## معرفی پروژه

هدف پروژه، تشخیص بالن قرمز با قطر تقریبی ۱٫۵ متر از فاصله حدود ۵۰۰ متر، با استفاده از دوربین ثابت Sony IMX477 با وضوح `4056×3040` پیکسل است.

در این فاصله، قطر بالن در تصویر حدود ۱۱٫۶ پیکسل برآورد می‌شود. به همین دلیل، حفظ جزئیات تصویر و تشخیص اهداف کوچک از چالش‌های اصلی پروژه است.

## قابلیت‌ها

- تشخیص اشیا با مدل آموزش‌دیده YOLO26s-p2
- تقسیم تصویر به وصله‌های `640×640` با هم‌پوشانی ۱۲۸ پیکسل
- استفاده از فیلترهای رنگ و حرکت برای بررسی اولیه تصویر
- آموزش با ترکیبی از تصاویر واقعی آسمان و نمونه‌های مصنوعی بالن
- حذف تشخیص‌های تکراری در وصله‌های هم‌پوشان
- ثبت اطلاعات تشخیص‌ها در فایل CSV
- ردیابی اهداف بین فریم‌ها
- تخمین تقریبی فاصله بر اساس اندازه هدف در تصویر و پارامترهای دوربین

## نتایج اعتبارسنجی مدل

نتایج ثبت‌شده روی مجموعه اعتبارسنجی:

| معیار | مقدار |
|---|---:|
| Precision | 0.964 |
| Recall | 0.974 |
| mAP@50 | 0.985 |
| mAP@50-95 | 0.851 |

این معیارها عملکرد مدل روی مجموعه اعتبارسنجی را توصیف می‌کنند و به‌تنهایی تضمین‌کننده عملکرد در شرایط عملیاتی نیستند.

### محدودیت‌های فعلی

- هنوز تصاویر یا ویدئوی واقعی ثبت‌شده با دوربین هدف IMX477 برای اعتبارسنجی نهایی در دسترس نیست.
- آزمایش‌های تخمین فاصله با نمونه‌های مصنوعی انجام شده‌اند؛ دقت فاصله باید با دوربین واقعی کالیبره شود.
- سرعت پردازش به سخت‌افزار، وضوح تصویر و تعداد وصله‌های بررسی‌شده وابسته است. در آزمایش فعلی روی ویدئوی ۴۰ فریمی با وضوح `4056×3040`، میانگین سرعت حدود ۵٫۴۹ فریم بر ثانیه ثبت شده است؛ این مقدار به هدف ۱۲ فریم بر ثانیه نمی‌رسد.
- عملکرد فیلتر حرکت و رنگ باید با ویدئوهای واقعی دوربین ارزیابی شود.

## نصب

Python و PyTorch سازگار با سخت‌افزار و نسخه CUDA سیستم خود را نصب کنید. سپس در PowerShell، از ریشه مخزن اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r .\delivery\requirements.txt
```

PyTorch باید متناسب با سیستم مقصد نصب شود؛ نصب آن به‌صورت یک نسخه ثابت برای همه سیستم‌ها در فایل وابستگی‌ها در نظر گرفته نشده است.

## اجرای تشخیص روی ویدئو

یک فایل ویدئویی در اختیار داشته باشید و مسیر آن را به اسکریپت بدهید:

```powershell
python .\delivery\final_inference.py `
  --source "C:\path\to\input.mp4" `
  --model ".\delivery\best.pt" `
  --output-video ".\delivery\output\result_video.mp4" `
  --output-csv ".\delivery\output\detections_log.csv"
```

مسیر ورودی را با مسیر واقعی ویدئوی خود جایگزین کنید. خروجی ویدئو و CSV در مسیرهای مشخص‌شده ذخیره می‌شوند.

گزینه‌های اجرا و جزئیات خروجی در [`delivery/README.md`](delivery/README.md) توضیح داده شده‌اند.
