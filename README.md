# 🎈 Red-Balloon-Tracker

سامانه تشخیص و ردیابی بالن‌های هواشناسی قرمز در فواصل دور با استفاده از بینایی ماشین و یادگیری عمیق.

## معرفی پروژه

هدف این پروژه، تشخیص و ردیابی بالن‌های قرمز با قطر تقریبی ۱٫۵ متر از فاصله حدود ۵۰۰ متر، با استفاده از دوربین ثابت IMX477 با وضوح `4056×3040` پیکسل است.

چالش اصلی پروژه، اندازه بسیار کوچک بالن در تصویر است؛ به‌طوری‌که در فاصله ۵۰۰ متری، قطر آن تقریباً ۱۱٫۶ پیکسل خواهد بود. تغییر اندازه مستقیم تصویر به ورودی استاندارد مدل‌های تشخیص اشیا می‌تواند اطلاعات بصری این اهداف کوچک را از بین ببرد.

برای حل این مسئله، سامانه از پردازش تصویر، تقسیم‌بندی هم‌پوشان فریم، فیلتر اولیه رنگ و حرکت و مدل تشخیص اشیا استفاده می‌کند.

## قابلیت‌ها و معماری

- **تشخیص اهداف کوچک:** استفاده از مدل `YOLO26s-p2` مبتنی بر Ultralytics.
- **تقسیم‌بندی هم‌پوشان (Overlapping Tiling):** تقسیم فریم به وصله‌های `640×640` با هم‌پوشانی ۱۲۸ پیکسلی، برای حفظ جزئیات اهداف کوچک.
- **فیلتر رنگ و حرکت:** استفاده از ماسک رنگی HSV و تفاضل فریم‌ها برای کاهش تعداد وصله‌های ارسالی به مدل.
- **تولید داده مصنوعی:** ترکیب بالن‌های کوچک با تصاویر پس‌زمینه آسمان برای افزایش تنوع داده‌های آموزشی.
- **تخمین فاصله:** تخمین تقریبی فاصله بالن بر اساس قطر آن در تصویر و پارامترهای دوربین.
- **ردیابی هدف:** پشتیبانی از ردیابی بین فریم‌ها؛ الگوریتم دقیق مورد استفاده در نسخه منتشرشده باید در این بخش مشخص شود.
- **حذف تشخیص‌های تکراری:** استفاده از NMS برای ادغام یا حذف تشخیص‌های تکراری ناشی از وصله‌های هم‌پوشان.

## نتایج اولیه

نتایج گزارش‌شده روی مجموعه اعتبارسنجی شامل تصاویر واقعی:

| معیار | نتیجه اولیه |
|---|---:|
| mAP@50 | 0.985 |
| Recall کلی | 0.974 |
| Recall اهداف کوچک‌تر از ۲۰ پیکسل | 1.000 |
| خطای تخمین فاصله تا ۶۵۰ متر | کمتر از ۶٪ |

این اعداد نتایج اولیه هستند و برای ارزیابی نهایی به مستندات آزمایش، مشخصات مجموعه داده و روش محاسبه معیارها نیاز دارند. نتایج مربوط به سرعت پردازش و FPS نیز باید جداگانه اندازه‌گیری و گزارش شوند.

## نصب و راه‌اندازی

پیش‌نیازها:

- Python
- PyTorch
- OpenCV
- Ultralytics
- وزن‌های آموزش‌دیده مدل

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/Mamad-MD/Red-Balloon-Tracker.git
cd Red-Balloon-Tracker
```

محیط مجازی ایجاد و فعال کنید:

```bash
python -m venv .venv
```

در ویندوز:

```powershell
.venv\Scripts\Activate.ps1
```

وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

## اجرا

نمونه دستورهای زیر الگو هستند و باید با رابط اجرای واقعی پروژه تطبیق داده شوند.

اجرای تشخیص و ردیابی روی ویدئو:

```bash
python track.py --source path/to/video.mp4
```

آموزش مدل:

```bash
python train.py
```

نام آرگومان‌ها، مسیر وزن‌ها و نحوه تعیین دستگاه پردازشی باید مطابق پیاده‌سازی واقعی پروژه تنظیم شوند.
